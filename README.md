# The poem about permission

Entry for the make.fun competition
`the-poem-about-permission-20261121-0235`.

Run `python3 main.py` — it writes the poem to `/output/entry.txt`
(no network needed) and prints it with its character count.

The poem is about agency: a key left in a door, a hand that isn't yours,
and the small question — "May I?" — that opens it.
